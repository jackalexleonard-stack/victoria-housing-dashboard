# Dashboard 2.2 — chart-polish fixes

> Executed subagent-driven (implement → adversarial review → fix), on `main`, one commit per item. User-reported 2026-07-21 after continued use of the live 2.1 site.

## X1 — HVI history depth (recon first)
Cotality's free `asx.json` feed is a rolling 365-day daily worm — the chart shows all the data that exists; the pipeline accumulates going forward. Recon: (a) confirm the feed's actual depth today; (b) does any free Cotality endpoint (monthly indices page/chart-pack data) offer longer monthly history to backfill? (c) if not: add a caption on the two HVI charts noting the rolling window ("Daily index — history accumulates from Jul 2025"), no source change. $0 constraint stands.

## X2 — annotation label collisions
`LineChart` renders every annotation label at `y = margin.t + 9`; dense clusters (2022–23 rate cycle) overlap into a mess. Fix: sort annotations by x; alternate labels between two rows; if a label's x-gap to the previously PLACED label (same row) is still < ~36px, keep the dashed marker line but skip the text. Lines always render; labels are best-effort. Detail view (wider) naturally shows more labels; cards fewer.

## X3 — tooltip placement
The multi-row tooltip anchors near the pointer (covering the hovered points) and clamps with a hard-coded 150px width (overflows for long names/many rows). Fix: side-switching — crosshair in the left half → tooltip to its right, else to its left; vertical position near the top of the plot, never over the highlighted dots; clamp using MEASURED tooltip dimensions (ref + useLayoutEffect) within the chart container, both axes.

## X4 — compact y ticks
Long tick labels (e.g. `1,000,000`) exceed the 44px left margin and clip to "00,000". Fix in `chartMath.ts` tick formatting: |v| ≥ 1e6 → `1.0M`; |v| ≥ 10_000 → `950k`; else current formatting. Percent charts unchanged (already suffixed). Applies to y and y2 ticks.

## X5 — per-row tooltip dates (reproduce first)
User: the popup shows one date but rows aren't always exactly at it. REPRODUCE before fixing: script over site.json — for every chart, do all its lines share identical date sets? Identify offenders (suspects: mixed-cadence compare overlays; any series whose metrics carry offset stamps). Fix: `atTime` includes each line's nearest point within a tolerance (half that line's median spacing) instead of exact-only; each tooltip row displays its OWN date when it differs from the header (small muted suffix). Compare overlays become honest (monthly line shows its month against a daily header).

## X6 — sticky data-table headers
`DataTable`'s `<thead>` scrolls away inside the `max-h-64 overflow-auto` container. Fix: `position: sticky; top: 0` on the header cells with `background: var(--card)` (and a low z-index) so headings persist while rows scroll.
